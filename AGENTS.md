

# AI News Hub
Агрегатор новостей, вакансий и заказов по теме нейросетей, вайбкодинга, ИИ-агентов и связанных платформ.


> Основано на [agents.md](https://agents.md/) — стандарт описания проектов для AI-ассистентов.

(React, Framer Motion, Tailwind, jQuery, любая другая) —

прежде чем писать код. Не полагайся на знания по памяти.

 Изменения должны быть точечными и относиться только к поставленной задаче.
- Используй существующие компоненты, хуки и паттерны проекта вместо добавления новых абстракций без необходимости.
- Для маршрутов редактируй исходные файлы в `src/routes/`, а не `src/routeTree.gen.ts`.

## Команды

- `npm run dev` — запустить локальный dev-сервер.
- `npm run build` — собрать production-версию.
- `npm run lint` — запустить ESLint.
- `npm run format` — отформатировать проект через Prettier.


## Как вносить изменения

1. **В collector.py** — логика парсинга, фильтрации, генерации страниц
2. **В _category_template.html** — верстка и JS всех страниц категорий
3. После любых правок запустить `python collector.py` для перегенерации всех файлов
4. commit только когда явно попросит пользователь

## Структура проекта

| Файл | Назначение |
|---|---|
| `collector.py` | Автосборщик: парсит RSS/API, раскладывает новости/вакансии/заказы по папкам |
| `_category_template.html` | Шаблон страницы категории (подставляются %%TITLE%%, %%ACCENT%%, %%ACT_*%%) |
| `index.html` | Главная (автогенерируемая сборщиком) |
| `ai/`, `vibe/`, `agent/`, `platform/`, `jobs/`, `orders/` | Категории, каждая содержит `index.html`, `data.js`, `news.json` |
